# Royal Frame Studios — Jaipur Luxury Wedding Photography SEO Project

## Project Overview
A complete SEO-optimized static website for a candid luxury wedding photography studio in Jaipur, India. Built as a 40-mark university Mini-Project.

## Tech Stack
- Static HTML5 / CSS3 / Vanilla JavaScript
- Ubuntu VPS (DigitalOcean) + Nginx
- Cloudflare DNS + CDN
- Let's Encrypt SSL (Certbot)
- Google Analytics 4
- Schema.org LocalBusiness + ImageObject structured data

## Folder Structure
- `index.html` — Homepage with hero + featured gallery + LocalBusiness schema
- `about.html` — Team + studio story
- `portfolio.html` — Gallery with ImageObject schema
- `pricing.html` — 3-tier packages (Silver / Gold / Royal)
- `blog-cost-guide.html` — 300-word SEO content page
- `contact.html` — Enquiry form + GA4 conversion tracking
- `css/style.css` — All styling
- `js/main.js` — Form + GA4 event tracking
- `robots.txt` / `sitemap.xml` — Technical SEO

## SEO Features
- LocalBusiness + ImageObject JSON-LD schema
- WebP image optimization + lazy loading
- Semantic HTML with keyword-rich alt tags
- Canonical tags + meta descriptions
- Mobile-responsive design
- GA4 `generate_lead` conversion event
